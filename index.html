Concepto de Contenedores y Herramientas

Los contenedores son unidades de software estándar que empaquetan el código y todas sus dependencias para que la aplicación se ejecute de manera rápida y confiable en cualquier entorno.

Servicios de Infraestructura para Cómputo en la Nube

La configuración de la infraestructura asegura que la aplicación web soporte cargas de trabajo reales de forma segura y escalable.

Servidor de Aplicaciones

Entorno de software que proporciona el entorno de ejecución para los componentes de la aplicación y lógica de negocio (ej. Node.js, Tomcat, Gunicorn).

Servidor de Base de Datos

Infraestructura dedicada a almacenar, gestionar y recuperar datos estructurados o no estructurados de manera segura (ej. MySQL, PostgreSQL, MongoDB).

Balanceo de Cargas

Distribución eficiente del tráfico de red entrante entre múltiples servidores backend para evitar sobrecargas y garantizar disponibilidad continua.

Configuración de Dominio

Asociación de una dirección legible por humanos (ej. tusitio.com) con la dirección IP pública del servidor donde se aloja la aplicación mediante registros DNS.

Certificados de Seguridad (SSL/TLS)

Protocolos criptográficos que cifran la conexión entre el navegador del usuario y el servidor, garantizando la privacidad e integridad de los datos (HTTPS).

Tipos de Pruebas de Software

Las pruebas garantizan que el sistema funcione correctamente, cumpla con los requisitos y esté libre de errores críticos antes de su despliegue final.

Caja Blanca

Pruebas basadas en la estructura interna, el código fuente y los caminos lógicos del sistema.

Caja Negra

Pruebas enfocadas en las entradas y salidas del sistema, sin evaluar el código interno.

Unitarias

Evaluación de componentes o funciones individuales de forma aislada.

Integración

Verificación de que diferentes módulos o servicios interactúan correctamente entre sí.

Regresión

Pruebas para confirmar que los cambios recientes en el código no rompieron funcionalidades existentes.

Rendimiento

Medición de la velocidad, capacidad de respuesta y estabilidad del sistema bajo carga.

Esfuerzo (Stress)

Prueba los límites del sistema sometiéndolo a una carga extrema superior a la habitual.

Usabilidad

Evaluación de qué tan intuitiva, accesible y fácil de usar es la interfaz para el usuario final.

Políticas, Normativa y Documentación

La fase final de liberación requiere cumplir con normativas de calidad y entregar manuales claros para los usuarios y administradores.

Políticas y Normativa

  • Estándares de codificación limpios y seguros (ej. OWASP Top 10).
  • Políticas de control de versiones y gestión de ramas (Git Flow).
  • Cumplimiento de normativas de privacidad y protección de datos.

Documentación y Manual de Usuario

Manual de Usuario: Guía detallada paso a paso orientada al usuario final que explica cómo navegar, utilizar las funciones principales y resolver dudas comunes dentro de la plataforma web.
